ML optimization

I optimize inference pipelines for recommendation and language models. My work spans TensorFlow graph execution, unused-op pruning, feature fusion, VNNI-aware kernels, and OpenVINO hybrid precision to improve throughput without giving away model quality.

MLC benchmarking

I design micro-benchmarks and proxy workloads to expose cache, memory, bandwidth, and latency behavior. Each study has controlled inputs, a known platform state, and results that can be compared across runs.

Systems debugging

I debug performance issues from workload behavior down to platform components, including memory, storage, networking, PCIe, virtualization, and kernel-facing accelerator paths.

Telemetry and regression

I combine EMON, health monitoring, and cycle-to-cycle regression testing to isolate root causes across more than 300 KPIs. The output is a defensible performance narrative, not just a chart.

Automation and validation

I build Python and Linux automation for multi-framework ML workloads, multi-node system health, test creation, workload profiling, proxy validation, and report generation from a single repeatable flow.
