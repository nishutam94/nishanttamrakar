Platform analysis

I characterize modern server platforms and trace performance outcomes back to the resources that constrain them. The work spans CPU behavior, cache and memory pressure, power limits, NUMA placement, interrupts, storage, and networking.

Workload engineering

I build controlled benchmark flows for database, key-value, vector, and systems workloads. Each run is tied to a clear question, a known platform state, and an output that can be compared with confidence.

TDX and virtualization

I work across trusted-domain virtualization, host readiness, VM launch configuration, and remote execution workflows. The goal is a validated environment before performance numbers are interpreted.

EMON and telemetry

I use EMON and related telemetry to explain IPC, CPI, top-down microarchitecture signals, memory bandwidth, frequency, power, and uncore behavior. The output is a defensible performance narrative, not just a chart.

Automation and reports

Python automation connects setup, execution, telemetry collection, comparison, and reporting. I preserve the state and decisions around a run so the next investigation starts from evidence instead of memory.
