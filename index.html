HOW I INVESTIGATE PERFORMANCE

WORKLOAD TO HARDWARE BEHAVIOR TO VALIDATION

Workload

Workload & baseline

I begin with workload characterization and a stable baseline: throughput, latency, CPU utilization, core scaling, frequency behavior, memory bandwidth, and power.

Controlled experiment

I vary one meaningful dimension at a time, such as core count, NUMA placement, frequency, workload size, or precision, while keeping platform state and run conditions explicit.

Telemetry & hardware behavior

I correlate application behavior with EMON, PMU counters, IPC, TMA, cache, memory, frequency, uncore, I/O, and power signals to identify the limiting subsystem.

Root cause & optimization

I turn the measured bottleneck into a testable hypothesis, then evaluate system tuning, workload changes, graph optimization, operator pruning, feature fusion, or FP32/INT8 trade-offs.

Validation

I repeat the experiment, compare against the baseline, check regression behavior, and preserve telemetry and report artifacts so the result can withstand review.

Workload→Baseline→Controlled experiment→Telemetry / EMON→Root cause→Optimization→Validation
